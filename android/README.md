# MediaHarvester для Android

Интерфейс на Kotlin + Jetpack Compose в стиле версии для ПК, а загрузки выполняет то же Python-ядро
(`../src/core`, `../src/utils`: yt-dlp, gallery-dl, анонимный разбор Instagram), запущенное внутри
приложения через [Chaquopy](https://chaquo.com/chaquopy/). Мост между ними: `app/src/main/python/mh_android.py`.

Версия приложения берётся из `../src/version.py`. Файлы сначала попадают во временную папку приложения,
затем переносятся в «Загрузки/MediaHarvester» через MediaStore (отдельные разрешения не нужны).

## Сборка

Нужны JDK 17, Android SDK (platform 35, build-tools) и Python 3.13 с лаунчером `py` (только для сборки).
В `local.properties` укажите `sdk.dir=...`.

```bash
./gradlew assembleDebug
```

Собираются два APK, по одному на архитектуру (каждый ≈ 100 МБ; общий был бы вдвое больше):
`app/build/outputs/apk/arm64/debug/app-arm64-debug.apk` — для телефонов (arm64-v8a, это почти все современные),
`app/build/outputs/apk/x64/debug/app-x64-debug.apk` — для эмулятора на ПК (x86_64). Быстрый цикл с эмулятором (пересборка + установка + запуск): `powershell -File dev.ps1`.
Релизные (подписанные, со сжатием кода R8) APK собирает `./gradlew assembleRelease`: `app/build/outputs/apk/arm64/release/` (≈77 МБ)
и `.../x64/release/` (≈80 МБ). Подпись берётся из `keystore.properties` рядом с `settings.gradle.kts`
(`storeFile`, `storePassword`, `keyAlias`, `keyPassword`; файл в git не попадает). Ключ лежит вне репозитория
(`~/android-dev/mediaharvester-release.jks`): **сохраните его копию и пароль** — без этого же ключа обновить
установленное приложение нельзя. Debug-сборку поверх release (и наоборот) поставить нельзя: сначала удалите приложение.

## Ограничения первой версии

- Android 10+ (arm64-v8a для телефонов, x86_64 для эмулятора; 32-битные устройства не поддерживаются).
- FFmpeg идёт внутри APK (бинарники и общие библиотеки из youtubedl-android, см. `Ffmpeg.kt`): склейка HD-видео
  и конвертация в MP3 работают как на компьютере. Из-за этого APK ≈ 125 МБ; позже можно разделить по архитектурам.
- Фото VK: вход через браузер (кнопка «Войти», затем скопировать адрес страницы — токен подхватывается из буфера и
  сразу очищается). Музыки VK пока нет.
- История: вкладка «История» (200 последних загрузок, повтор ссылки одним нажатием).
- Настройки: тема, «Только по Wi-Fi», название папки в «Загрузках», версии yt-dlp/gallery-dl и обновление yt-dlp
  (скачивается с GitHub и подключается после перезапуска), журнал для отправки, очистка временных файлов.
- Аккаунты (cookies): блок «Аккаунты» — вход во встроенном браузере (Instagram, YouTube, TikTok, X, Reddit,
  Pinterest) или импорт `cookies.txt`. Сессии лежат в закрытой папке приложения и склеиваются в один файл для
  yt-dlp/gallery-dl. Публичные посты Instagram всё равно пробуются анонимно первыми. Google может не пустить во
  встроенный браузер: для YouTube тогда нужен импорт `cookies.txt`.
- «Треки по списку» работает: вкладка «Треки по списку», поиск на YouTube → MP3 с тегами; повторный запуск того же списка не плодит копии в «Загрузках».
