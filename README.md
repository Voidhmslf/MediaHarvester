## Зачем это

Проект появился из личной задачи: нужно было скачать альбом ВКонтакте на 300 фото, а делать это руками можно с ума сойти. Потом к альбомам добавились остальные соцсети, и получилась программа, у которой одна цель: вставил ссылку, нажал кнопку, получил файлы в лучшем качестве, которое отдаёт сайт.

Внутри работают yt-dlp (видео и аудио), gallery-dl (фото, галереи, ленты), собственный код для фотоальбомов VK и для публичных постов Instagram, а ffmpeg склеивает дорожки. Выбирать между ними не нужно, программа определяет платформу по ссылке сама.

## Скачать и запустить

Готовый файл лежит на странице [релизов](https://github.com/Voidhmslf/MediaHarvester/releases/latest): `MediaHarvester.exe`, около 110 МБ. Положите его в любую папку и запустите. Устанавливать ничего не надо, ffmpeg уже внутри.

Рядом лежит `SHA256SUMS.txt`. Если хотите убедиться, что файл не повреждён, сравните сумму:

```powershell
Get-FileHash .\MediaHarvester.exe -Algorithm SHA256
```

Три вещи, о которых лучше знать заранее:

- **SmartScreen и антивирусы.** Файл собран PyInstaller и не подписан сертификатом (подпись платная). Windows может написать «Неизвестный издатель»: нажмите «Подробнее» и «Выполнить в любом случае». Defender иногда срабатывает ложно на такие сборки. Код открыт, при желании [соберите файл сами](#сборка-exe).
- **Не подменяйте `.exe`, пока программа запущена.** Для gallery-dl и окна входа VK программа запускает собственный файл как вспомогательный процесс и проверяет, что родитель тот же самый. Если файл заменили на ходу, появится «Security validation failure». Закройте все окна и запустите новый файл.
- **Только Windows.** Проверялось на Windows 11. Часть кода (буфер обмена через Win32, окно входа VK на WebView2) работает только там. На Linux и macOS запуск не проверялся.

Свои данные программа хранит в `%LOCALAPPDATA%\MediaHarvester`: настройки (`settings.json`), лог (`logs`) и свежая версия yt-dlp (`yt-dlp`).

## Что умеет

| Сервис | Что скачивается | Нужен ли вход |
| :--- | :--- | :--- |
| YouTube, YouTube Music | Видео до 4K, Shorts, плейлисты, аудио в MP3 | Нет. Для видео 18+ и сообщения «подтвердите, что вы не бот» нужны cookies |
| ВКонтакте | Фотоальбомы в максимальном размере, видео и клипы | Для альбомов нужен токен, для публичных видео нет |
| Instagram | Reels, публичные посты и карусели (фото и видео), Stories | Для Reels и публичных постов нет. Для Stories и закрытых аккаунтов нужны cookies |
| TikTok | Видео, профиль целиком, фотопосты и слайдшоу | Нет |
| X (Twitter) | Видео и фото из постов, медиа профиля | Бывает нужны cookies |
| Pinterest | Пины, доски и профили | Нет |
| Reddit | Видео, картинки, галереи, сабреддиты и профили | Нет |
| SoundCloud | Треки, плейлисты, профили целиком | Нет |
| Треки по списку | MP3 с YouTube по списку «Исполнитель — Название» | Нет |
| Любой другой сайт | Всё, что поддерживает yt-dlp ([список сайтов](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)) | Зависит от сайта |

Профили, доски и сабреддиты бывают огромными, поэтому за один раз программа берёт первые 500 файлов. Списки, которые обычно нужны целиком (плейлист SoundCloud, профиль TikTok), скачиваются полностью.

Музыка из VK через их API сейчас не работает: VK закрыл её для сторонних программ. Что делать вместо этого, написано в разделе [Музыка](#музыка).

### Как программа выбирает способ скачивания

| Ссылка | Чем качается |
| :--- | :--- |
| YouTube, YouTube Music, SoundCloud, TikTok (видео и профиль), пост на X, пост на Reddit | yt-dlp |
| Фотопост TikTok, профиль X, Pinterest, сабреддит или профиль Reddit | gallery-dl |
| Reel в Instagram | yt-dlp |
| Пост или карусель в Instagram (`/p/...`) | собственный анонимный запрос, а если не вышло или заданы cookies, то gallery-dl |
| Stories и профиль в Instagram | gallery-dl, обычно нужны cookies |
| Видео и клип VK | yt-dlp |
| Фотоальбом VK (`vk.com/album-123_456`) | VK API, нужен токен |
| Музыка VK | vkpymusic, см. ограничения ниже |
| Всё остальное | yt-dlp |

Если выбранный движок ошибся с типом контента, программа переключается на другой сама. Например, yt-dlp сказал, что в посте нет видео, значит, там фото, и ссылка уходит в gallery-dl. А если gallery-dl ничего не нашёл, он пробует yt-dlp. Бесконечных кругов между ними не бывает.

## Как пользоваться

1. Вставьте ссылку в поле «Ссылка на источник». Справа появится плашка с распознанной платформой. Можно вставить сразу несколько ссылок, [по одной в строке](#очередь).
2. Для видео выберите качество: «Максимальное (Авто)», 4K, 2K, Full HD, 720p, 480p, 360p или «Только аудио (MP3)». Кнопка «Проверить» покажет, какие разрешения есть именно у этого видео. Если ссылка ведёт на плейлист и нужны все ролики, отметьте галочку «Скачивать весь плейлист».
3. Проверьте папку сохранения (по умолчанию «Загрузки»).
4. Нажмите «Начать скачивание». Кнопка закреплена внизу окна, её видно при любой прокрутке. Пока идёт загрузка, она превращается в «Остановить скачивание».

Состояние показывает строка внизу: цветная точка, текст, процент и полоска прогресса. После загрузки в ней появляется кнопка «Открыть папку».

Верхний список «Режим загрузки» по умолчанию стоит на «Автоопределении». Вручную режим нужен редко, например когда ссылка нестандартная:

| Режим | Когда нужен |
| :--- | :--- |
| Автоопределение (Smart) | почти всегда |
| Видео / Аудио | принудительно отправить ссылку в yt-dlp |
| Instagram | принудительно использовать способ для Instagram |
| Галереи и посты | принудительно отправить ссылку в gallery-dl |
| Фотографии ВК (Альбом) | альбом VK, поле токена показывается сразу |
| Музыка ВК | плейлист, профиль или трек VK (см. ограничения) |
| Треки по списку | скачать музыку по списку названий |

### Куда падают файлы

Видео и аудио лежат прямо в выбранной папке, а плейлист получает подпапку с названием списка. Остальное раскладывается так:

| Что | Папка |
| :--- | :--- |
| Альбом VK | `VK_Album_<id владельца>_<id альбома>` |
| Музыка VK | `VK_Music_...` |
| Треки по списку | `Треки_по_списку` |
| Посты Instagram без входа | `Instagram_Downloads` |
| Остальные фото и галереи | `<Платформа>_Downloads`, например `Pinterest_Downloads` |

### Очередь

Ссылки можно вставить пачкой или добавлять по одной кнопкой «Добавить в очередь» (или клавишей Enter). Скачиваются они по порядку, в строке состояния виден номер вроде `[2/5]`. Ошибка на одной ссылке не останавливает остальные: неудавшиеся остаются в списке с причиной, и следующий запуск возьмёт только их. Готовые можно убрать кнопкой «Убрать готовые». «Остановить скачивание» прерывает всю очередь, файлы, которые уже скачались, остаются на месте.

### Оформление и ввод

Тема переключается кнопкой с луной или солнцем в шапке. На экране «Справка» есть ещё вариант «Как в системе»: при первом запуске программа так и делает, а дальше помнит ваш выбор.

В полях ввода работают Ctrl+C, Ctrl+V, Ctrl+X и Ctrl+A в любой раскладке, а правая кнопка мыши в полях ссылки и токена открывает меню (вырезать, копировать, вставить, выделить всё).

## Instagram

- **Reels** скачиваются без входа.
- **Публичные посты и карусели** тоже без входа. Программа запрашивает данные поста у Instagram анонимно, как это делают сайты-загрузчики, берёт все слайды в максимальном размере и качает фото и видео напрямую.
- **Stories и закрытые аккаунты** требуют cookies (см. [ниже](#cookies)).
- Если в блоке «Cookies» уже выбран браузер или файл, анонимный способ пропускается и сразу работает gallery-dl с вашим входом. Если анонимный запрос не удался (закрытый аккаунт, лимит запросов), программа тоже переходит на gallery-dl.

Анонимный доступ держится на внутренних механизмах yt-dlp, и Instagram время от времени их ограничивает. yt-dlp обновляется автоматически, но если однажды пост перестанет скачиваться без входа, выберите браузер в блоке «Cookies».

## Музыка

### Треки по списку

Режим для тех, у кого музыка лежит в VK или где угодно ещё, а скачать её напрямую нельзя. VK при этом вообще не трогается и токен не нужен.

Вставьте список, по одному треку в строке: `Исполнитель — Название`. Подходят разделители « - », « – », « — » и « | » (с пробелами вокруг), нумерация и маркеры в начале строки игнорируются, пустые строки и строки с `#` пропускаются. Список можно скопировать из плейлиста VK или из архива данных, который VK выдаёт по запросу.

Для каждого трека программа ищет на YouTube восемь вариантов и выбирает самый похожий: учитывает совпадение названия и исполнителя, любит каналы «Topic» и официальные загрузки, а лайвы, каверы, ремиксы, караоке и часовые версии отбрасывает. Результат сохраняется в `Треки_по_списку` как MP3 с тегами исполнителя и названия. Уже скачанное пропускается, поэтому прерванный список можно запустить снова. Треки, которые найти не удалось, записываются в `_not_found.txt`.

Это не те же файлы, что в VK, а ролики с YouTube, и редкие треки могут не найтись.

### Музыка ВКонтакте

Режим «Музыка ВК» формально есть: он принимает ссылку на плейлист, трек (`vk.com/audio...`) или профиль, до 1000 треков за раз. Но VK закрыл музыкальные методы API для сторонних программ. Токен Kate Mobile сейчас отвечает ошибками 9 и 3, токены других приложений ошибкой 15. Кнопка «Проверить токен» покажет, что именно отвечает у вас.

Есть экспериментальная кнопка «Эксперимент: войти как официальное приложение VK». Она заходит от имени приложения VK для Android. Это нарушает правила VK, и аккаунт могут ограничить или заблокировать, поэтому перед включением показывается предупреждение, а пользоваться ей лучше на запасном аккаунте. Безопасный вариант один: треки по списку.

## ВКонтакте: альбомы и вход

Для фотоальбомов нужен токен доступа. Он выдаётся на ваш аккаунт, пароль программа не видит и не хранит.

1. Нажмите «Войти через ВКонтакте». Откроется ваш обычный браузер со страницей VK.
2. Подтвердите доступ и скопируйте адрес открывшейся страницы (Ctrl+L, затем Ctrl+C). Токен лежит в этом адресе.
3. Программа следит за буфером обмена до десяти минут, сама забирает токен и очищает буфер.

Запасные способы: кнопка «Войти во встроенном окне» (нужен Edge WebView2; VK ID не всегда отдаёт в нём токен) и ручная вставка ссылки или токена в поле.

Токены для фото и для музыки выдают разные приложения VK, поэтому они хранятся отдельно и подставляются сами при смене режима. Сохраняются они в `settings.json` в открытом виде, не отправляйте этот файл никому.

Как качаются альбомы: восемь потоков, повтор при сбое, пропуск уже скачанных файлов (запустите ту же ссылку ещё раз, и докачаются только недостающие). Если у фото крупный вариант отвечает ошибкой, берётся следующий по размеру. Что не удалось скачать, попадёт в `_failed.txt` в папке альбома. Если фото не скачивается ни в каком размере, оно, скорее всего, удалено или скрыто.

## Cookies

Cookies нужны, только если без них не обойтись: Stories и закрытые аккаунты Instagram, видео YouTube 18+, сообщение «подтвердите, что вы не бот», иногда посты X. Публичные посты, карусели и Reels Instagram скачиваются и так.

**Из браузера (проще).** В блоке «Cookies» выберите браузер, где вы вошли в аккаунт: Firefox, Chrome, Edge, Opera, Opera GX, Brave или Vivaldi. Лучше всего работает Firefox. Браузеры на Chromium держат базу cookies занятой, пока открыты, поэтому на время скачивания их нужно закрыть, а у свежих версий Chrome шифрование иногда мешает чтению совсем. Тогда берите Firefox или файл.

**Файлом.**
1. Поставьте расширение, которое экспортирует cookies, например [Get cookies.txt LOCALLY](https://chrome.google.com/webstore/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc).
2. Войдите в нужный сайт и экспортируйте файл в формате Netscape.
3. В блоке «Cookies» нажмите «Обзор» и выберите файл. Файл главнее браузера.

Cookies читаются локально и никуда не отправляются, в логах и отчётах они маскируются.

## Если что-то пошло не так

Вместо трассировки программа показывает короткую причину и подсказку, что делать. Кнопка «Подробнее» (появляется в строке состояния после ошибки) открывает окно с причиной по каждой ссылке, кнопкой «Скопировать отчёт» и кнопкой «Открыть папку логов». В отчёте система, версии Python, yt-dlp и ffmpeg, тексты ошибок и последние 60 строк лога. Токены и ключи в ссылках там скрыты, так что отчёт можно прикладывать к [issue](https://github.com/Voidhmslf/MediaHarvester/issues).

Лог лежит в `%LOCALAPPDATA%\MediaHarvester\logs\mediaharvester.log`, при этом хранятся три файла по 1 МБ.

**Видео скачивается только в 360p.** YouTube отдаёт качественное видео и звук отдельными потоками, склеивает их ffmpeg. Под заголовком программы должна быть строка вроде `ffmpeg 7.1`. Если ffmpeg помечен красным, значит, он не найден или не запускается: скачайте `.exe` заново (при запуске из исходников переустановите `imageio-ffmpeg`).

**Instagram просит войти.** Для Reels и публичных постов этого быть не должно. Если Instagram всё же отказал (закрытый аккаунт, Stories, временный лимит), выберите браузер или файл в блоке «Cookies».

**Не качается музыка VK.** Это ограничение самого VK, см. [Музыка](#музыка). Используйте «Треки по списку».

**Часть фото альбома VK не скачалась.** Откройте `_failed.txt` в папке альбома и запустите ту же ссылку ещё раз.

**Скачивание вдруг перестало работать на сайте, который работал вчера.** Сайты меняются, и yt-dlp приходится это догонять. Программа проверяет новую версию yt-dlp при запуске не чаще раза в 12 часов, скачивает её в профиль, сверяет SHA-256 с контрольными суммами из релиза и подключает при следующем запуске. Если появилась строка «обновлён до ... перезапустите программу», перезапустите. Автообновление отключается галочкой «Автоматически обновлять yt-dlp» в блоке папки.


## Запуск из исходников

Нужны Python 3.11 или новее и Git. Тесты проходят на 3.11 и 3.14.

```powershell
git clone https://github.com/Voidhmslf/MediaHarvester.git
cd MediaHarvester
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Отдельно качать ffmpeg не нужно: его приносит пакет `imageio-ffmpeg`. При запуске из исходников настройки лежат не в профиле, а в `settings.json` в корне проекта (файл в `.gitignore`). Лог и обновления yt-dlp остаются в `%LOCALAPPDATA%\MediaHarvester`.

## Сборка .exe

```powershell
pip install pyinstaller
pyinstaller --clean --noconfirm MediaHarvester.spec
```

Файл появится в `dist\MediaHarvester.exe`. Версия берётся из [`src/version.py`](src/version.py) и попадает в свойства файла (Проводник, Свойства, Подробно). Заодно её же показывают заголовок окна, экран «Справка» и лог, а тест следит, чтобы README и CHANGELOG не отстали.

Что сделано в сборке отдельно:

- Обычный вызов `sys.executable -m gallery_dl` в собранной программе снова запустил бы окно (получилась бы «fork-бомба»), поэтому `main.py` ловит служебные флаги `--gallery-dl-worker` и `--vk-login-worker` и запускает нужный модуль напрямую.
- В файл упакованы ffmpeg, шрифты Inter, логотип, темы `customtkinter` и окно входа `pywebview`.
- Из сборки исключены тяжёлые пакеты, которые программе не нужны (scipy, pandas, numpy, Jupyter и другие). Без этого файл весил бы около 180 МБ.

### Тесты

```powershell
python -m unittest discover -s tests -t .
```

Сейчас их около 180. Сеть они не трогают (вместо неё локальные серверы и подмена yt-dlp), в ваш профиль ничего не пишут. GUI-тесты открывают настоящее окно, поэтому на машине без рабочего стола их отключают переменной `MH_SKIP_GUI=1`.

| Файл | Что проверяет |
| :--- | :--- |
| `test_router.py` | платформа, тип и движок по ссылке |
| `test_core_helpers.py` | настройки, вспомогательные функции, форматы yt-dlp и gallery-dl |
| `test_insta_anon.py` | анонимная загрузка постов Instagram |
| `test_vk_photos.py`, `test_vk_auth.py`, `test_vk_diag.py` | альбомы VK, вход, проверка токена |
| `test_tracks.py`, `test_music_tokens_input.py` | треки по списку, токены, ввод с клавиатуры |
| `test_errors.py`, `test_ytdlp_updater.py` | тексты ошибок, лог, обновление yt-dlp |
| `test_ui_structure.py` | состав окна, движок для каждой ссылки, очередь |
| `test_theme.py` | контраст цветов в обеих темах, переключение темы, шрифты |
| `test_scrolling.py` | колесо мыши и тачпад |
| `test_version.py` | версия одна и та же в коде, README и CHANGELOG |
