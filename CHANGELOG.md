# Список изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по [SemVer](https://semver.org/lang/ru/).

## [1.2.1] — 2026-10-26

### Добавлено
- **Версия для Linux** (x86_64): AppImage и архив с `install.sh` (меню приложений, иконка, команда `mediaharvester`). Собирается на glibc 2.31 и запускается на Ubuntu 20.04+, Debian 11+, Fedora, Arch и других. Проверена на Ubuntu 22.04, Debian 12, Fedora и Arch. Для Linux сделаны шрифт Inter через fontconfig, иконка окна, Ctrl+C/V/X/A в любой раскладке, масштаб для HiDPI (`GDK_SCALE`, `Xft.dpi`, `MH_SCALE`), вход VK через обычный браузер и Chromium в списке браузеров для cookies. Сборка и проверка в Docker: `packaging/linux`.
- **Flake для Nix и NixOS** (`flake.nix`, `packaging/nix`): `nix run github:Voidhmslf/MediaHarvester`, пакет и overlay для `configuration.nix`. Программа собирается из исходников, Python, yt-dlp, gallery-dl и ffmpeg берутся из nixpkgs, а vk_api и vkpymusic — с PyPI. Проверено в контейнере nixos/nix на nixos-unstable: окно под Xvfb, загрузка видео со склейкой дорожек.
- Переменные окружения для системных пакетов: `MH_FFMPEG` задаёт путь к ffmpeg, `MH_NO_SELF_UPDATE=1` выключает скачивание свежего yt-dlp (и прячет переключатель автообновления). Если папка программы недоступна для записи, `settings.json` сохраняется в папку данных пользователя.
- **Приложение для Android** (папка `android/`, APK в релизе): очередь ссылок, «Треки по списку», плейлисты и каналы, фото ВКонтакте, вход в аккаунты и импорт `cookies.txt`, «Поделиться» из других приложений, история, настройки, субтитры, MP3/M4A/Opus с обложкой, фоновая загрузка с уведомлением и ожиданием Wi-Fi. Использует то же ядро (`src/core`) через Chaquopy; Kotlin и Jetpack Compose в фирменном стиле.
- Ядро: параметры `audio_codec`, `embed_cover`, `subtitle_langs`, `playlist_limit` у загрузки видео, скорость и остаток времени в строке состояния, разбор названия и обложки ссылки без скачивания (`probe_media`). Для Windows поведение по умолчанию не изменилось.

### Исправлено
- Перенос подсказок в карточках применяется сразу при запуске: раньше без первого события изменения размера окна (бывает в тайловых оконных менеджерах) строка обрезалась по краям.
- **Прокрутка колесом мыши и тачпадом** срабатывала через раз. Причины: колесо доставлялось виджету с фокусом (например, кнопке «Начать скачивание» вне области прокрутки), а флаг Shift «залипал» после переключения раскладки (Alt+Shift, Ctrl+Shift). Теперь область определяется по положению указателя, Shift не учитывается, мелкие шаги тачпада накапливаются, а длина щелчка колеса стала заметной (~72 px). Текстовое поле списка треков по-прежнему листает себя само.

## [1.2.0] — 2026-10-26

Новый внешний вид под фирменный стиль и светлая тема.

### Добавлено
- **Светлая и тёмная тема:** кнопка с луной/солнцем в шапке переключает оформление на лету; на экране «Справка» можно выбрать «Как в системе», «Светлая» или «Тёмная». Выбор сохраняется, первый запуск следует теме Windows.
- **Фирменный стиль:** логотип «знак + надпись» в шапке, новая иконка окна и `.exe`, акцентный цвет harvest `#D9480F` из брендбука `MediaHarvester-brand`.
- **Шрифт Inter** (лицензия OFL, файлы в `assets/fonts`) подключается только для программы, в систему ничего не устанавливается.
- Главная кнопка «Начать скачивание» закреплена внизу окна: видна при любой прокрутке карточек.
- Заголовок окна Windows 11 окрашивается под тему приложения.
- Тесты на палитру (контраст текста ≥ 4,5:1 в обеих темах), переключение темы и шрифты.

### Изменено
- Переработан весь интерфейс: единая система цветов и скруглений, поля ввода с подсветкой фокуса, плашки-статусы, крупное поле ссылки, аккуратный статус-бар с цветной точкой состояния.
- Высота окна подбирается под рабочую область экрана, чтобы нижняя часть не уходила под панель задач.
- Палитра и стили вынесены из `config.py` в `src/ui/theme.py`.

## [1.1.0] — 2026-10-25

Большое обновление: больше платформ, очередь ссылок, Instagram без входа, быстрые фотоальбомы VK, автообновление yt-dlp
и понятные ошибки. Код приложения разбит на модули и покрыт автотестами.

### Добавлено
- **Очередь ссылок:** вставка сразу нескольких ссылок, последовательная загрузка с номером `[2/5]`, повтор только неудавшихся, общая отмена.
- **Новые платформы:** TikTok, X (Twitter), Pinterest, Reddit, SoundCloud. Режим «Галереи и посты»; автоматический откат между yt-dlp и gallery-dl без зацикливания; ленты (доски, профили, сабреддиты) ограничены 500 файлами; списки (плейлист SoundCloud, профиль TikTok) качаются целиком сами.
- **Instagram без входа:** публичные посты и карусели (фото и видео, все слайды в максимальном размере) скачиваются анонимно; gallery-dl с cookies остаётся запасным путём.
- **Cookies из браузера:** Firefox, Chrome, Edge, Opera, Opera GX, Brave, Vivaldi (для Instagram, YouTube и др.); файл `cookies.txt` по-прежнему главнее.
- **Автообновление yt-dlp:** новая версия скачивается в профиль пользователя, проверяется по SHA-256 и подключается при следующем запуске без переустановки программы; при старте проверяется ffmpeg; версии показаны в шапке.
- **Понятные ошибки:** перевод технических причин (сеть, 403/404/429, регион, 18+, DRM, диск, длинные пути, VK API и др.) в короткое сообщение с подсказкой; окно «Подробнее» с копированием отчёта; лог с ротацией в `%LOCALAPPDATA%\MediaHarvester\logs` и маскировкой токенов и ключей в ссылках.
- **ВКонтакте:**
  - фотоальбомы в 8 потоков с повторами, докачкой, отчётом `_failed.txt` и запасными размерами, если крупный вариант отвечает 404;
  - вход через браузер с автоматическим захватом токена из буфера обмена (буфер очищается), встроенное окно входа как запасной вариант;
  - отдельные токены для фото и музыки;
  - кнопка «Проверить токен» (диагностика методов API, без записи токена в лог);
  - ссылки на отдельные песни (`vk.com/audio…`) и домен `vk.ru`.
- **Треки по списку:** режим, который по списку «Исполнитель — Название» находит и скачивает треки в MP3 с тегами через YouTube, без обращения к VK; отчёт `_not_found.txt`, докачка при повторном запуске.
- **Экспериментальный вход музыки VK через приложение VK для Android** с обязательным предупреждением о рисках для аккаунта.
- **Ввод:** Ctrl+C / V / X / A в любой раскладке, контекстное меню по правой кнопке, системный буфер обмена Windows (устраняет «залипание» вставки).
- **Версия приложения** отображается в заголовке окна, в «Справке», в логе и в свойствах `.exe`.
- **Автотесты:** 150+ тестов (роутер, движки, очередь, ошибки, обновление yt-dlp, вход VK, интерфейс).

### Изменено
- Интерфейс (`app.py`, 2000+ строк) разбит на 9 модулей-миксинов в `src/ui/`; логика загрузки вынесена из окна.
- Настройки в собранном `.exe` теперь хранятся в `%LOCALAPPDATA%\MediaHarvester\settings.json`; раньше при выходе из программы они терялись (рабочая папка PyInstaller временная).
- Из сборки исключены лишние пакеты (научный стек, Jupyter и др.): `.exe` весит около 105 МБ вместо 180 МБ.
- Роутер определяет платформу по хосту и пути, а не по подстроке в ссылке.
- README и «Справка» обновлены под новые режимы.

### Исправлено
- Бесконечные откаты между yt-dlp и gallery-dl для постов без видео.
- Ложное сообщение «токен не принят» при ограничении частоты VK (ошибка 9).
- Надпись «Буфер обмена пуст» не пропадала после удачной вставки.
- Обрезание длинных подсказок при масштабировании Windows.
- Не записывались теги MP3 (не хватало `mutagen`).
- Утечка файла логотипа при запуске.

### Известные ограничения
- **Музыка VK через API недоступна:** VK закрыл методы для сторонних программ (ошибки 3, 9, 15). Используйте «Треки по списку».
- Встроенное окно входа VK может не получить токен от VK ID; основной способ входа — через обычный браузер.
- Анонимный доступ к Instagram держится на внутренних механизмах yt-dlp и может временно ограничиваться; для Stories и закрытых аккаунтов нужны cookies.
- Для cookies из Chrome, Edge и Opera браузер нужно закрыть; Firefox работает без этого.
- Не заменяйте `MediaHarvester.exe`, пока программа запущена: запущенная копия не сможет стартовать рабочие процессы.
- Проверено на Windows 11; на Linux и macOS сборка и работа не тестировались.
